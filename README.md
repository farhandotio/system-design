# System Design Learning

My personal learning notes as I work through [Free System Design](https://freesystemdesign.com/). This repository is for studying, understanding, and reviewing system design concepts.

## Daily Routine

1. Choose the next lesson from the [roadmap](ROADMAP.md).
2. Study the lesson and explain the main idea in my own words.
3. Create a dated note in that phase's folder using its lesson template. Foundations has a [dedicated template](templates/foundations-lesson.md); other phases can use the [general template](templates/daily-learning.md).
4. Add the note to the phase README and update my progress in the roadmap.

Name each note `YYYY-MM-DD-topic.md`. A lesson is complete when I can explain its idea, one trade-off or failure mode, and a question or takeaway.
